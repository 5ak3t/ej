# ej 0.0.1.post1 (2026-10-09)

Packaging release of ej 0.0.1: the model, the weights and the code paths are unchanged
([0.0.1 release notes](0.0.1.md)).

- **PyPI:** `pip install ejai`. The distribution is named `ejai` because `ej` is taken on PyPI; the import name stays `ej`.
- **Dependencies:** ranges instead of exact pins; the lower bounds are the versions 0.0.1 was tested with; transformers
  stays below 5.19 (5.19 needs torch >= 2.6).
- **Weights:** unchanged, https://huggingface.co/5ak3t/ej, tag `v0.0.1`; `ej.load("5ak3t/ej", revision="v0.0.1")`.
