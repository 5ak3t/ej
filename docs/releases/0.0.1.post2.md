# ej 0.0.1.post2 (2026-10-09)

Packaging fix of ej 0.0.1: the model, the weights and the code paths are unchanged
([0.0.1 release notes](0.0.1.md), [0.0.1.post1](0.0.1.post1.md)).

- **Fix:** `pip install ejai` now installs `sentencepiece` and `protobuf`, which the prediction runtime imports; with
  0.0.1.post1 alone, `ej.load(...)` failed with `No module named 'sentencepiece'`.
- **Install:** `pip install ejai` (import name `ej`). Weights: https://huggingface.co/5ak3t/ej, tag `v0.0.1`;
  `ej.load("5ak3t/ej", revision="v0.0.1")`.
